# Ribarnica Plavi Talas

Staticki sajt napravljen samo HTML + CSS + JavaScript.

Stranice:
- index.html — Početna
- proizvodi.html — Proizvodi i cene
- o-nama.html — O nama, vlasnici i lokacija
- kontakt.html — telefon, Facebook, adresa i kontakt forma
- style.css — kompletan dizajn
- script.js — mobilni meni, filter proizvoda, godina i kontakt forma
