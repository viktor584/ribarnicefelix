# Ribarnica Plavi Talas

Staticki sajt napravljen samo HTML + CSS + JavaScript.

Stranice:
- index.html — Početna
- proizvodi.html — Proizvodi i cene
- o-nama.html — O nama, vlasnici i lokacija
- kontakt.html — telefon, Facebook, adresa i kontakt forma
- style.css — kompletan dizajn
- script.js — mobilni meni, filter proizvoda, godina i kontakt forma

VAŽNO:
Podaci su primeri. Zameniti naziv, adresu, telefon, Facebook link, vlasnike, radno vreme i cene stvarnim podacima.
Za Google Maps zameniti placeholder div sa Google Maps Embed iframe kodom.
Kontakt forma trenutno samo prikazuje potvrdu u browseru; za stvarno slanje treba backend ili servis za forme.
